# Templates

Reusable project templates for AI_WORKSPACE.

## Available Templates

### docker-compose-basic

Basic Docker Compose example using the `hello-world` image.

Use it to verify:

- Docker Engine
- Docker Compose
- Docker Hub image pulling
- Local Docker permissions

### uv-python-basic

Basic Python project initialized with `uv`.

Use it to verify:

- Python runtime
- uv project initialization
- uv virtual environment workflow
- `uv run` execution
