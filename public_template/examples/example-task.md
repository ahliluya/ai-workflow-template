# Example Task: Create a Docs Checklist / 示例任务：创建文档清单

## Goal / 目标

Create `docs/checklist.md` with a short bilingual pre-commit checklist. / 创建 `docs/checklist.md`，包含简短的双语提交前清单。

## Scope / 范围

- Allowed: `docs/checklist.md` only. / 仅允许：`docs/checklist.md`。
- Do not delete, rename, use paid services, or edit other files. / 不删除、不重命名、不使用付费服务、不编辑其他文件。

## Steps / 步骤

1. Inspect documentation style. / 检查文档风格。
2. Create the checklist. / 创建清单。
3. Check formatting and Git status. / 检查格式和 Git 状态。

## Acceptance checks / 验收检查

- The file exists and is bilingual. / 文件存在且为双语。
- It contains no private data. / 不包含私人数据。
- `git diff --check` passes. / `git diff --check` 通过。

## Stop conditions / 停止条件

Stop if the file has unrelated changes or the scope is unclear. / 文件存在无关变更或范围不清时停止。
