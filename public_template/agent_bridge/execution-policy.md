# Execution Policy / 执行策略

1. Inspect the relevant files. / 检查相关文件。
2. Confirm scope, permissions, and stop conditions. / 确认范围、权限和停止条件。
3. Make small, reversible changes. / 进行小型、可逆的修改。
4. Run the agreed checks. / 运行约定的检查。
5. Report changes, evidence, and risks. / 报告变更、证据和风险。
6. Review before committing; back up at stable milestones when needed. / 提交前审查；需要时在稳定里程碑备份。
