# Cost Policy / 成本策略

- Default to zero extra API cost. / 默认零额外 API 成本。
- Require approval for paid services, including a budget and stop condition. / 付费服务必须获得批准，并设定预算和停止条件。
- Avoid automatic loops, background agents, and unnecessary broad scans. / 避免自动循环、后台智能体和不必要的大范围扫描。
- Prefer small, independently verifiable tasks. / 优先采用小型、可独立验证的任务。
