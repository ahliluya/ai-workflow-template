# Cost Policy / 成本策略

## Default policy / 默认策略

- Zero extra API cost by default. / 默认零额外 API 成本。
- No API billing unless the User explicitly approves the purpose and budget. / 未经用户明确批准用途和预算，不启用 API 计费。
- No automatic loops. / 不运行自动循环。
- No background agents. / 不运行后台智能体。
- Prefer small, scoped, independently verifiable tasks. / 优先使用小型、范围明确、可独立验证的任务。
- Avoid broad or token-heavy scans unless the task requires them. / 除非任务需要，避免大范围或高 Token 消耗扫描。

Before future paid automation, document the service, data scope, estimated cost, spending limit, and stop condition. / 未来启用付费自动化前，应记录服务、数据范围、预计成本、支出上限和停止条件。
