# FAQ / 常见问题

## Does this require an API? / 是否需要 API？

No. The templates work with people or local tools. Paid services are optional and require approval. / 不需要。模板可由人员或本地工具使用。付费服务是可选项，且需批准。

## Is a specific agent required? / 是否必须使用特定智能体？

No. Any controlled tool can follow the task, result, and review formats. / 不必须。任何受控工具都可遵循任务、结果和审查格式。

## Can beginners use it? / 初学者可以使用吗？

Yes. Start with one documentation file and review every change. / 可以。从一个文档文件开始，并审查每项变更。

## What should stay out of Git? / 哪些内容不应进入 Git？

Secrets, credentials, personal data, private notes, logs, backups, and generated machine state. / 秘密、凭据、个人数据、私人笔记、日志、备份和机器生成状态。

## Where should private context live? / 私人上下文应存放在哪里？

Use protected storage outside the public repository. Keep this template generic. / 使用公开仓库之外的受保护存储，并保持本模板通用。
