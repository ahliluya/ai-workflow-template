# Frequently Asked Questions / 常见问题

## Does this require API access? / 是否需要 API？

No. The default workflow uses manual ChatGPT and local Codex usage with zero extra API cost. API billing is not enabled by this template. / 不需要。默认工作流采用人工使用 ChatGPT 和本地 Codex，零额外 API 成本。本模板不会启用 API 计费。

## Is Codex required? / 是否必须使用 Codex？

No. Codex is the recommended local executor, but a person or another carefully controlled local tool can follow the same templates. / 不必须。Codex 是推荐的本地执行者，但用户本人或其他受控本地工具也可以遵循相同模板。

## Can beginners use it? / 初学者可以使用吗？

Yes. Start with one small documentation task, list exact allowed files, and review every change before committing. / 可以。从一个小型文档任务开始，列出准确的允许文件，并在提交前审查每项变更。

## What should not be committed? / 哪些内容不应提交？

Do not commit secrets, credentials, API keys, personal data, private memory, inbox content, logs, backups, archives, machine-specific state, or private repository information. / 不要提交秘密、凭据、API 密钥、个人数据、私人记忆、inbox 内容、日志、备份、归档、机器专用状态或私人仓库信息。

## How is private memory different from the public template? / 私人记忆与公开模板有何区别？

Private memory contains user-specific context and history and should remain in protected local storage. The public template contains only generic structures, policies, and examples that anyone can reuse safely. / 私人记忆包含用户专属上下文和历史，应保存在受保护的本地存储中。公开模板仅包含任何人都可安全复用的通用结构、策略和示例。
