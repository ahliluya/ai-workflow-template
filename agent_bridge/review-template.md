# Review Template / 审查模板

Use this checklist for human or ChatGPT review after Codex reports completion. / Codex 报告完成后，供用户或 ChatGPT 使用此清单审查。

## Review decision / 审查决定

- Task passed / 任务是否通过：Yes / No / Conditional — 是 / 否 / 有条件
- Scope respected / 是否遵守范围：Yes / No
- Sensitive files touched / 是否触及敏感文件：No / Yes — list and explain / 列出并说明
- Verification sufficient / 验证是否充分：Yes / No — missing checks / 缺少的检查
- Commit allowed / 是否允许提交：Yes / No / After fixes — 是 / 否 / 修复后允许
- Backup needed / 是否需要备份：No / Yes — milestone and reason / 里程碑与原因
- Next action / 下一步操作：Continue / Pause / Rollback — 继续 / 暂停 / 回滚
