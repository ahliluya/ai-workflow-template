# Cost Policy / 成本策略

## Zero-Extra-Cost Default / 默认零额外成本

- Default to zero extra cost. / 默认保持零额外成本。
- Prefer ChatGPT Plus and included Codex CLI usage. / 优先使用 ChatGPT Plus 与已包含的 Codex CLI 使用额度。
- No API billing unless the user explicitly approves the exact purpose and budget. / 未经用户明确批准具体用途和预算，不启用 API 计费。
- No automatic loops. / 不运行自动循环。
- No background agents. / 不运行后台智能体。
- No token-heavy full-repository scans unless necessary for the approved task. / 除非已批准任务确有必要，不进行高 Token 消耗的全仓库扫描。
- Prefer small, scoped, independently verifiable tasks. / 优先采用小型、范围明确、可独立验证的任务。

## Future API Use / 未来 API 使用

Before future API usage, record a cost-risk note covering the provider, model or service, data scope, estimated usage, spending limit, stop condition, and human approval. API access remains disabled until that review is complete.

未来使用 API 前，必须记录成本风险说明，包括提供方、模型或服务、数据范围、预计用量、支出上限、停止条件和人工批准。完成审查前，API 访问保持关闭。
